# New3

## Repository layout

- `netdiagpeer/` - Python application for peer-to-peer network diagnostics with CLI, Tkinter GUI, report export, and Windows-focused checks
- `rename_dirs.sh` - separate Bash utility for swapping folder-name parts like `part1_part2 -> part2_part1`

## NetDiagPeer quick start

Run from the repository root:

```bash
python netdiagpeer/main.py --session office-test
```

Project documentation and the Windows build script are inside:

```text
netdiagpeer/
```
